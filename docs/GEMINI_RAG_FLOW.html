Mindmap: Document Analysis Flow

📄 User Uploads Document
📤 Send to Backend API
💾 Store in MinIO
🤖 Send to Gemini API
🔍 Extract Metadata
📊 Store in Database
✅ Return to Frontend

Detailed Flow

1. Document Upload

User selects file (Image/PDF)
File: receipt.jpg / invoice.pdf
Type: image/jpeg, application/pdf
Frontend creates FormData
formData.append('file', selectedFile)
formData.append('workspaceId', workspaceId)
formData.append('transactionId', transactionId)
POST to backend
POST /api/documents/upload
Content-Type: multipart/form-data

2. Backend Processing

Validate request (auth, workspace access)
requireAuth(headers)
requireWorkspaceAccess(userId, workspaceId)
Upload to MinIO
s3Client.putObject({
  Bucket: 'novajournal-docs',
  Key: uniqueKey,
  Body: file
})
Get file URL from MinIO
fileUrl: http://localhost:9000/novajournal-docs/xxx.jpg

3. Gemini AI Analysis

Prepare prompt for Gemini
"Extract metadata from this document:
- Document type (receipt, invoice, contract)
- Amount/currency
- Date
- Vendor/merchant
- Line items
- Categories"
Call Gemini API
gemini.generateContent({
  prompt: analysisPrompt,
  image: fileBuffer
})
Parse response to structured JSON
{
  "documentType": "invoice",
  "amount": 150.00,
  "currency": "USD",
  "date": "2024-09-14",
  "vendor": "Amazon",
  "lineItems": [...],
  "categories": ["electronics"]
}

4. Database Storage

Create document record
INSERT INTO documents (
  id, workspaceId, transactionId,
  fileName, fileUrl, fileType,
  metadata, uploadedBy
)
Store extracted metadata as JSONB
metadata: {
  "documentType": "invoice",
  "amount": 150.00,
  "extractedText": "...",
  "entities": [...]
}
Return success to frontend
201 Created
{
  "success": true,
  "data": { document, metadata }
}

Extracted Metadata Fields

📄 Document Type receipt, invoice, contract, receipt, statement
💰 Amount Numeric value with currency
📅 Date ISO format date
🏪 Vendor/Merchant Company name
📝 Line Items Array of items with prices
🏷️ Categories Auto-categorized tags
📄 Extracted Text OCR text content
🔍 Entities Names, addresses, IDs

API Endpoints

Endpoint Method Description Auth Required
/api/documents/upload POST Upload document, analyze with Gemini, store metadata Yes
/api/documents/list/:workspaceId GET List all documents with metadata Yes
/api/documents/:id GET Get single document with full metadata Yes
/api/documents/:id DELETE Delete document and metadata Yes

Implementation Components

Backend: Gemini Service

// src/services/gemini.ts
import { GoogleGenerativeAI } from '@google/generative-ai';

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY);

export async function analyzeDocument(fileBuffer: Buffer, mimeType: string) {
  const model = genAI.getGenerativeModel({ model: 'gemini-pro-vision' });
  const prompt = `Extract metadata...`;
  const result = await model.generateContent([prompt, fileBuffer]);
  return parseMetadata(result.response.text());
}

Backend: Document Route

// src/routes/documents.ts
.post('/upload', async ({ request, headers, set }) => {
  const authResult = await requireAuth(headers);
  const formData = await request.formData();
  const file = formData.get('file') as File;
  
  // Upload to MinIO
  const fileUrl = await uploadToMinIO(file);
  
  // Analyze with Gemini
  const metadata = await analyzeDocument(fileBuffer, file.type);
  
  // Store in DB
  const document = await db.insert(documents).values({...});
  return { success: true, data: document };
})

Database Schema

// src/db/schema.ts
export const documents = pgTable('documents', {
  id: text().primaryKey(),
  workspaceId: text().notNull(),
  transactionId: text(),
  fileName: text().notNull(),
  fileUrl: text().notNull(),
  fileType: text().notNull(),
  metadata: jsonb().$type(),
  uploadedBy: text().notNull(),
  uploadedAt: timestamp().defaultNow()
});

Error Handling

Status Code Error Code Description
400 INVALID_FILE Unsupported file type or corrupted file
413 FILE_TOO_LARGE File exceeds size limit (e.g., 10MB)
500 GEMINI_ERROR Failed to analyze with Gemini API
500 MINIO_ERROR Failed to upload to MinIO storage
500 DB_ERROR Failed to store metadata in database
